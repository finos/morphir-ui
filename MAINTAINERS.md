## Updating this file

Manage every addition, removal, or correction through a pull request to this file. If Morphir governance requires a vote, link the public vote from the pull request. This keeps a public record of project leadership.

Email [morphir-maintainers-private@lists.finos.org](mailto:morphir-maintainers-private@lists.finos.org) with maintainer questions, and notify [help@finos.org](mailto:help@finos.org) when maintainership changes.
